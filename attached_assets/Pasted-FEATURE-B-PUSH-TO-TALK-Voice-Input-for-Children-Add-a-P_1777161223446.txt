FEATURE B — PUSH TO TALK (Voice Input for Children)
Add a Push to Talk voice input system to the Homework Helper chat screen. This is NOT a phone call — it is a press-and-hold microphone button that records the child’s voice, converts it to text, sends it to Adam, and Adam responds with voice and text.
PUSH TO TALK BUTTON: Replace the current small microphone icon with a large circular button at the bottom center of the chat screen. Make it big enough for small fingers — minimum 80px diameter. Color: bright orange with a white microphone icon. Label below it says “Hold to talk 🎤” / “اضغط وحكي 🎤”. When child holds the button: button pulses with a glowing animation, show a sound waveform animation so child knows their voice is being captured, show text “Listening… 👂” / “عم استمع… 👂”. When child releases the button: show a thinking animation on Adam’s character with a thought bubble, show text “Adam is thinking… 🤔” / “آدم عم يفكر… 🤔”, then play Adam’s response in voice automatically and show the text on screen.
SPEECH TO TEXT: Use OpenAI Whisper API for converting child’s voice to text. Store API key as OPENAI_API_KEY in environment variables. Whisper handles both Arabic and English automatically — no need to specify language, it detects automatically. This is critical for children who mix Arabic and English in the same sentence.
NOISE HANDLING: If the recorded audio is less than 1 second, ignore it and show “Try again, I didn’t hear you! 🎤” / “حاول مرة ثانية، ما سمعتك! 🎤”. If Whisper returns empty or unclear text, Adam says “Hmm I didn’t quite catch that! Can you say it again a little louder? 💪” / “همم ما فهمت كويس! قولها مرة ثانية بصوت أعلى شوي؟ 💪”.
KEEP TYPING AVAILABLE: Keep the text input bar available above the Push to Talk button. Some children and parents prefer typing. The layout should be: text input bar on top, then camera and image buttons, then the large Push to Talk button at the bottom. This serves all ages.
COST FOR PUSH TO TALK: OpenAI Whisper costs $0.006 per minute of audio. Average child voice message is 5–10 seconds. Cost per message is approximately $0.001. For 100 users sending 30 voice messages per day: 100 x 30 x $0.001 = $3 per day = $90 per month. This is very affordable and worth the massive improvement in experience for young children.
ANIMATIONS FOR PUSH TO TALK: When button is pressed — show red recording dot in top right corner of screen like a real recording indicator. When Adam is processing — show Adam character doing a funny thinking pose, eyes looking up, finger on chin. When Adam responds — show Adam character doing a small happy jump animation before speaking.
ADD VOICE ONBOARDING: The first time a child opens the Homework Helper, show a fun tutorial screen with Adam explaining how to use the voice button. Adam says: “Hey superhero! See this big orange button? Hold it and ask me ANYTHING — math, English, Arabic, anything! I’m all ears! 🦸🎤” / “هلا يا بطل! شايف هالزر البرتقالي الكبير؟ اضغط عليه وسألني أي شي — رياضيات، إنجليزي، عربي، أي شي! أنا كلي آذان! 🦸🎤”. Show an animated finger pressing the button so child knows exactly what to do. This tutorial shows only once and is skippable
